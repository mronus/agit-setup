# agit-setup

[agit](https://github.com/mronus/agit) is a distribution of Git that
records how much of each commit was written by AI coding agents. It is
a drop-in replacement for `git`: same command, same repositories, plus
provenance.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/mronus/agit-setup/main/install.sh | sh
```

Integrations that connect coding agents to agit through their hooks
are coming to this repository.
